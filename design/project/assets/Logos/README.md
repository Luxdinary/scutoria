# Logos

- `scutum-mark.svg`: der Scutum-Schild, Strich 1,8 in `#4f8cff` (`accent` dunkel), für dunkle Flächen. Aus der Marke des alten Shops kopiert; der Pfad ist exakt.
- `scutum-mark-ink.svg`: dieselbe Marke in `#141a24` (`ink` Papier) für Papier-Dokumente und Druck. Eine Farbe; sie steht in der Datei, weil ein `<img>` keine Farbe erben kann.
- `favicon.svg`: die 64-px-Kachel, Grund `#0a0c10` mit 14 px Eckenradius, Marke in `#4f8cff`. Unverändert aus dem alten Shop.

Schutzraum um die Marke: eine Schildbreite. Mindestgröße 20 px am Bildschirm. Nicht umfärben, füllen, drehen oder mit Effekten versehen. Das Wortzeichen ist Text (siehe Markenbuch), kein Bild.
