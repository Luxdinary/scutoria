EvidencePage (Nachweisseite) ist die datierte Zusammenfassung, die ein Betrieb auf den Tisch legt: was geregelt ist, was offen ist, wer unterschrieben hat, wann die nächste Prüfung fällig ist.

Aufgebaut auf DocumentPage, immer auf Papier. Kicker „Evidence summary“ und das Produkt in `label`; der Titel nennt den Betrieb; eine `stamp`-Zeile mit Erstellungsdatum, Prüfdatum und Dokumentnummer. Dann die Nachweisliste: eine Zeile je Punkt mit Datum oder Anzahl in `doc-caption` und einer Pill rechts, grün „Regulated“, gelb „Review due“, rot „Open“. Offene Punkte werden aufgeführt, nie weggelassen. Eine Unterschriftszeile für den Betrieb schließt die Seite. Die Seite entsteht aus den Antworten des Toolkits und trägt dieselbe Dokumentnummer wie die Dateien, die sie zusammenfasst.

Der Verwender liefert Betriebsname, Daten, die Punkte mit Status und die Nummer.
